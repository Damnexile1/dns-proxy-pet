# Техническое задание: DNS + Proxy сервис с подписками

## 1. Описание проекта

**Название:** [Название проекта - определить]

**Цель:** Создать коммерческий сервис обхода блокировок для пользователей из РФ через DNS + HTTP/HTTPS прокси с системой подписок через Telegram бота.

**Целевая аудитория:** Пользователи из России, нуждающиеся в доступе к заблокированным ресурсам

**Бизнес-модель:** Подписка (ежемесячная/годовая) через Telegram бота с автоматической оплатой

---

## 2. Функциональные требования

### 2.1 Основной функционал

#### DNS-сервер
- Прием DNS-запросов от клиентов
- Определение заблокированных доменов (черный список)
- Перенаправление запросов к заблокированным доменам через прокси
- Прямое разрешение незаблокированных доменов
- Кеширование DNS-ответов
- Логирование запросов (минимальное, для статистики)

#### HTTP/HTTPS Прокси-сервер
- Обработка HTTP/HTTPS трафика
- Поддержка CONNECT метода для HTTPS
- Аутентификация пользователей (по токену/логину)
- Ограничение скорости по тарифам
- Подсчет трафика пользователей
- Ротация IP-адресов (опционально)

#### Система управления пользователями
- Регистрация через Telegram бота
- Генерация уникальных учетных данных (токен/логин-пароль)
- Управление подписками (активация/деактивация)
- Проверка статуса подписки в реальном времени
- Учет использованного трафика
- Блокировка неактивных/просроченных подписок

#### Telegram бот
- Регистрация новых пользователей
- Просмотр статуса подписки
- Оплата подписки (интеграция с платежной системой)
- Получение настроек подключения
- Инструкции по настройке
- Техподдержка (FAQ + обращения)
- Уведомления (истечение подписки, проблемы с сервисом)

#### Платежная система
- Интеграция с ЮKassa / Cryptomus (крипта)
- Автоматическое продление подписки
- Webhook для обработки платежей
- История платежей
- Возврат средств (опционально)

#### Административная панель (опционально для MVP)
- Просмотр статистики пользователей
- Управление тарифами
- Мониторинг серверов
- Управление черным списком доменов
- Просмотр логов и метрик

### 2.2 Тарифные планы (примерные)

- 1 устройство
- Безлимитный трафик
- Стандартная скорость

**Семейный:**

## 4. Технический стек

### Backend
- **Язык:** Go 1.22+
- **DNS-сервер:** Custom на Go (github.com/miekg/dns)
- **Прокси:** Custom HTTP/HTTPS proxy на Go
- **API:** Gin / Fiber framework
- **База данных:** PostgreSQL 15+ (пользователи, подписки, платежи)
- **Кеш:** Redis (сессии, DNS кеш, rate limiting)
- **Message Queue:** RabbitMQ / NATS (обработка платежей, уведомления)

### Telegram Bot
- **Библиотека:** telebot / telegram-bot-api (Go)
- **Функции:** Регистрация, оплата, поддержка, инструкции

### Инфраструктура
- **Контейнеризация:** Docker + Docker Compose
- **Оркестрация:** Docker Swarm / Kubernetes (для масштабирования)
- **CI/CD:** GitHub Actions / GitLab CI
- **Мониторинг:** Prometheus + Grafana + Loki
- **Reverse Proxy:** Nginx
- **SSL:** Let's Encrypt (Certbot)

### Платежи
- **ЮKassa API** (для рублей)
- **Cryptomus / CryptoCloud** (для крипты, опционально)

### Хостинг
- **Локация:** За пределами РФ (Нидерланды, Германия, Финляндия)
- **Провайдер:** Hetzner / DigitalOcean / Vultr
- **Конфигурация (старт):**
  - 4 vCPU
  - 8 GB RAM
  - 100 GB SSD
  - 5-10 TB трафик/месяц
  - Стоимость: ~$40-60/месяц

## 6. База данных (PostgreSQL)

### Таблицы:

#### users
```sql
id              SERIAL PRIMARY KEY
telegram_id     BIGINT UNIQUE NOT NULL
username        VARCHAR(255)
created_at      TIMESTAMP DEFAULT NOW()
updated_at      TIMESTAMP DEFAULT NOW()
```

#### subscriptions
```sql
id              SERIAL PRIMARY KEY
user_id         INTEGER REFERENCES users(id)
plan_type       VARCHAR(50) -- 'basic', 'premium', 'family'
status          VARCHAR(50) -- 'active', 'expired', 'cancelled'
started_at      TIMESTAMP
expires_at      TIMESTAMP
auto_renew      BOOLEAN DEFAULT TRUE
created_at      TIMESTAMP DEFAULT NOW()
updated_at      TIMESTAMP DEFAULT NOW()
```

#### proxy_credentials
```sql
id              SERIAL PRIMARY KEY
user_id         INTEGER REFERENCES users(id)
token           VARCHAR(255) UNIQUE NOT NULL
login           VARCHAR(255) UNIQUE
password        VARCHAR(255)
max_devices     INTEGER DEFAULT 1
created_at      TIMESTAMP DEFAULT NOW()
```

#### payments
```sql
id              SERIAL PRIMARY KEY
user_id         INTEGER REFERENCES users(id)
subscription_id INTEGER REFERENCES subscriptions(id)
amount          DECIMAL(10,2)
currency        VARCHAR(10)
payment_method  VARCHAR(50) -- 'yookassa', 'crypto'
status          VARCHAR(50) -- 'pending', 'completed', 'failed'
external_id     VARCHAR(255) -- ID от платежной системы
created_at      TIMESTAMP DEFAULT NOW()
updated_at      TIMESTAMP DEFAULT NOW()
```

#### traffic_usage
```sql
id              SERIAL PRIMARY KEY
user_id         INTEGER REFERENCES users(id)
bytes_used      BIGINT DEFAULT 0
date            DATE
created_at      TIMESTAMP DEFAULT NOW()
```

#### blocked_domains
```sql
id              SERIAL PRIMARY KEY
domain          VARCHAR(255) UNIQUE NOT NULL
added_at        TIMESTAMP DEFAULT NOW()
```

## 7. API Endpoints

### Аутентификация
- `POST /api/v1/auth/register` - Регистрация через Telegram
- `POST /api/v1/auth/verify` - Проверка токена

### Пользователь
- `GET /api/v1/user/profile` - Профиль пользователя
- `GET /api/v1/user/subscription` - Статус подписки
- `GET /api/v1/user/credentials` - Получить данные для подключения
- `GET /api/v1/user/traffic` - Статистика трафика

### Подписки
- `POST /api/v1/subscription/create` - Создать подписку
- `POST /api/v1/subscription/renew` - Продлить подписку
- `POST /api/v1/subscription/cancel` - Отменить автопродление

### Платежи
- `POST /api/v1/payment/create` - Создать платеж
- `POST /api/v1/payment/webhook` - Webhook от платежной системы
- `GET /api/v1/payment/history` - История платежей

### Прокси (внутренний API)
- `POST /api/internal/proxy/auth` - Проверка аутентификации пользователя
- `POST /api/internal/proxy/traffic` - Учет трафика

## 10. Риски и митигация

### Технические риски
- **Блокировка серверов:** Использовать несколько IP-адресов, ротация
- **DDoS атаки:** Cloudflare, rate limiting, fail2ban
- **Проблемы с производительностью:** Мониторинг, автоскейлинг
- **Утечка данных:** Минимальное логирование, шифрование

### Юридические риски
- **Хостинг за пределами РФ:** Обязательно
- **Анонимность:** Не хранить личные данные, только Telegram ID
- **Платежи:** Использовать легальные платежные системы

### Бизнес риски
- **Конкуренция:** Уникальное УТП, качественный сервис
- **Отток пользователей:** Стабильность, поддержка, конкурентные цены
- **Проблемы с монетизацией:** Гибкие тарифы, пробный период
