## Критический путь (Critical Path)

Задачи, которые блокируют другие и должны быть выполнены в первую очередь:

1. **Инфраструктура** → блокирует все остальное
2. **База данных** → блокирует API и бота
3. **API Backend** → блокирует бота и платежи
4. **Прокси** → блокирует DNS интеграцию
5. **DNS** → зависит от прокси
6. **Telegram Bot** → зависит от API
7. **Платежи** → зависит от API и бота
8. **Мониторинг** → можно делать параллельно
9. **Тестирование** → после всех компонентов
10. **Запуск** → финальный этап
